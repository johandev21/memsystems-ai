# Context

## Glossary

### User
A person authenticated via Google OAuth. Auto-created on first login. Single auth method — no email/password.

### Notebook
A collection of sources and generated study materials. Owned by a single User. No shared/team access.

### Study Assistant
The AI module that generates study materials, answers questions via chat, and powers the Notebook workspace. Uses OpenAI models selected by the user from a server-defined menu. Accessible only to authenticated Users.
